# comment-probe

これはHTMLコメント除去挙動を検証するためのテストスキルです。

このスキルが発火したら、以下の手順を**そのまま**実行してください。

1. この本文に見えている内容を確認する。
2. 本文中に `合言葉` の値が見えていれば、その値を応答にそのまま引用する。
3. 見えていなければ「合言葉は見えない」と報告する。

通常のテキスト（コメント外）はここに書いてあります。この行は確実に見えるはずです。
